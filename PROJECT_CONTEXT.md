## What this project is
A capped-downside **R&D** project: an autonomous trading agent on Robinhood's Agentic MCP, funded with a small, ring-fenced cash balance. The goal is to **learn agentic/market engineering on real infrastructure**, not to generate income.
- **1%/week is an aspirational north star, NOT a success gate.** Do not optimize toward it or treat missing it as failure. (the return target is explicitly aspirational.)
- **The backtest is a kill-switch.** Prove a strategy survives realistic costs out-of-sample *before* any real money. Most likely outcome for most strategies is "doesn't beat SPY net of costs" — and correctly showing that is a success, not a failure.
- **The LLM orchestrates a FIXED strategy library.** It never free-form trades, never invents strategies. Deterministic rules only.

## The four test objects — and the counterintuitive bits you must NOT "fix"
- **S1 — Trend-following (risk-control sleeve).** Judged on **drawdown**, explicitly NOT on beating SPY's CAGR. It is *expected* to lag SPY in bull markets. That is correct behavior, not a bug.
- **S2 — Cross-sectional momentum, run on the 9 sector ETFs (XLK, XLF, …), NOT single stocks.** Single-name backtests on MCP data are survivorship + look-ahead biased (only currently-listed tickers exist; a 2026 large-cap list backtested to 2005 is rigged) and can *fabricate* the edge. Sector SPDRs are survivorship-clean and are the only momentum results allowed to gate a decision. Single-name momentum may be run but is "directional only" and NEVER gates. **Do not swap in hot single stocks to make it look better.**
- **S3 — Short-term mean reversion = the NULL-CONFIRMATION test.** Expected to be ≈ break-even-to-negative after honest costs (the academic edge is an illiquidity premium that dies after costs in liquid names). Its job is to **prove the harness can correctly KILL a weak strategy.** Do NOT tune it to look profitable. If it somehow passes the gate, that is a red flag to audit the cost model, not a win.
- **S4 — The blend = trend-gated momentum (S1 ⊕ S2).** This is Antonacci's dual-momentum, one coherent object. Mean reversion is tested as a *measured add-on* to see if it helps — NOT baked into the blend at an arbitrary weight.

## Cost model — NOT a flat percentage
Zero commission; SEC/FINRA fees are rounding-error. **The real cost is the bid-ask spread crossed with weak price improvement** (Robinhood PFOF → model paying ~the full spread, not midpoint). Backtest estimates spread via the **Corwin-Schultz** high-low estimator (auto-widens in volatility); live/paper charges the **actual real-time bid/ask**. **S3 is charged ≥0.45%** (it dip-buys exactly when spreads are widest), not its cheap ETF tier. Costs stress-scale (2008/2020 fills cost multiples of calm-period fills). See `COST_MODEL.md`. **Do not replace this with a flat 0.2%.**

## Methodology guards (the anti-self-deception layer — these exist because reviewers caught real bugs)
- **No look-ahead:** the 52-week-high is computed from historical bars, NEVER from the live `get_equity_fundamentals` snapshot (which is today's value). Signals fire on completed bars; fills are at the next open.
- **Gap-through stops fill at the gapped-down OPEN, never at the stop price.** Filling at the stop fabricates downside protection and flips a FAIL to a PASS.
- **Shared T+1 settled-cash ledger:** a sale frees buying power next trading day, never same-day (conservative Good-Faith-Violation proxy).
- **Multiple-testing correction:** Deflated Sharpe Ratio + Probability of Backtest Overfitting, with auto-kill thresholds — because testing many variants inflates the best one by luck.
- **Walk-forward + forced 2008/2020/2022 stress folds;** deep-bear behavior beyond those is explicitly an extrapolation, not a measurement.
- **Price-return (split-adjusted) bars** are the backtest basis. _Correction (2026-06-17):_ the MCP **cannot** supply dividend-inclusive total return for the deep history — `adjustment_type='all'` is a broken **subtractive** adjustment (drives 2009 prices negative) that carries **no dividends before ~2013** (verified: the `split−all` offset is frozen across every 2008 ex-date), and there is no dividend-history tool or total-return index. Returns are therefore **price-return (ex-dividend)**; the limitation is documented in `STRATEGY_TESTING_SPEC.md` §3.1 and mainly affects the bond sleeve / 60-40 benchmark (an optional later coupon-accrual refinement). Equity strategy-vs-benchmark comparisons are largely unbiased (both sides ex-dividend).

## MCP / account reality (verified live by direct inspection — no orders were placed)
- The agentic account is a **CASH** account (`agentic_allowed=true`), options off, **currently unfunded**. No margin, no PDT — only T+1 settlement governs, and only for re-deploying the *same* dollars (selling is unconstrained).
- The main account is **walled off** from the agent (`agentic_allowed=false`).
- **Native stop orders are supported** (`stop_market`/`stop_limit`, `gfd`/`gtc`); there is `ref_id` idempotency and a `review_equity_order` pre-flight. No native trailing stop.
- **Data comes from the MCP itself:** `get_equity_historicals` reaches back to 2005 (use `adjustment_type='split'` — the clean, non-negative price series; `'all'` is broken for history, see §3.1 correction) — this is the backtest data source, no external feed. `get_equity_quotes` is real-time with bid/ask.
- Full detail: `MCP_CAPABILITIES.md`.

## Hard guardrails for the build phase
- **OFFLINE only.** The backtest/foundation code does NOT call the MCP and does NOT trade. Never place/review/cancel a real order or move money during the build. Going live is a separate, later, explicitly-authorized phase — not part of Plans 01-04.
- Branch off `main`; never commit straight to `main`.

## Process discipline
Every plan/spec is pressure-tested by **three independent adversarial reviews** before it is acted on. This already happened for the feasibility proposal, the strategy spec, and Plan 01 — each round caught real errors (a margin-rule category error, a 52-week-high look-ahead landmine, a tautological cost test). Build **canary-first**: the cost/settlement/stop simulator is golden-tested before any strategy depends on it.

**Capabilities-first (added 2026-06-17, learned the hard way).** Before planning or building toward any spec requirement that depends on an external data source, **empirically verify the source can actually meet it** — a spec mandate is a hypothesis about the data, not a fact. Task 7 burned hours and ~6 review subagents designing two total-return reconstruction methods before discovering the MCP cannot supply total return for the deep history at all (`adjustment_type='all'` is broken — see the §3.1 correction in the spec and the data-limitation note above). The fix that should have come first: one systematic capability sweep of the data source, then a plan that fits reality. When a data problem surfaces, map the whole option space rather than drilling piecemeal into one mechanism. The hard-won data findings + cache-build quirk handling are recorded in `scripts/build_price_cache.py` (the reproducible Task-7 cache build: IWM-2005 split back-adjust, mis-adjusted-bar repair, interpolated-gap forward-fill, discontinuity gate).

## LIVE-01 track — authorized exceptions (dated decision log)
- **2026-06-22 — Spec §5 consciously SUSPENDED for the LIVE-01 single-name paper-monitor (authorized by the operator).** Spec §5 admits to paper-trading only strategies that clear the §4 backtest kill-switch. Single-name selection is **un-backtestable** — survivorship + forward-selection bias + today-only fundamentals (§3.7) mean a single-name backtest can *fabricate* the edge — so "only §4-passers reach paper" cannot apply to it. LIVE-01 therefore runs the single-name trend/trailing-stop strategy **forward / paper-only by necessity**, with **risk management as the load-bearing part, not an entry edge** (the safety model flips from "prove it first" to "control damage live"). This is a conscious, recorded exception, not a silent course change. Scope: **review-only** ($0 account, `review_equity_order` only — never places); it does **not** relax §5 for any §4-eligible ETF/sector strategy.
